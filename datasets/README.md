# Datasets

Benchmark questions and ground-truth data for evaluating knowledge retrieval modes.

## benchmark-questions.json

25 questions across 7 categories:

- **project-overview** — High-level project understanding
- **retrieval-comparison** — Direct document vs graph vs hybrid
- **evidence-tracing** — Following evidence chains
- **provenance** — Provenance tracing and completeness
- **evaluation** — Evaluation harness and metrics
- **architecture-decisions** — Why certain design choices were made
- **agent-safety** — Governance and agent constraint mechanisms
- **contradictions** — Contradiction detection and handling
- **ontology** — Entity kinds, relation types, schema design
- **technology-stack** — Technology choices and comparisons
- **domain-model** — Entity and relation model design
- **architecture** — System architecture and pipeline
- **evidence-synthesis** — Combining multiple evidence sources

Each question specifies expected entities and relations for automated evaluation.
