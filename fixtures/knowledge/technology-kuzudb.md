## Description

KuzuDB was an embedded graph database that pioneered columnar storage for graph workloads. Acquired by Apple in 2025, the open-source repository was archived.

## Supersession

LadybugDB continues the KuzuDB vision with the same core team, maintaining Cypher compatibility and embedded operation. All KuzuDB references in this project should migrate to LadybugDB.
